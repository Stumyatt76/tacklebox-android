# Original paid Android purchases

The install-date allowance keeps existing eligible installations working, but does not survive uninstall. It is not a receipt. Journal backups never grant purchase access.

The Unlimited screen now provides an explicit recovery route for original paid-app customers, including those who have already reinstalled. They contact the existing support mailbox with their original Google Play order reference. The app opens a draft; it sends nothing automatically. Do not request journal files, passwords or payment-card details.

Support must verify the original **uk.co.tacklebox.app paid-app order** in Play Console, including purchase date and refund/cancellation status. Do not issue access solely from an install date, an unverified screenshot or a self-declared order number. Record fulfilled orders privately to avoid duplicate issuance.

For an eligible order, issue one unused Google Play one-time promotion code for the active **tacklebox_unlimited** product. This is a free non-consumable entitlement, not a refund or another paid purchase. Create codes in Play Console and observe its expiry, region and quarterly limits. If codes are exhausted, keep the request open and escalate to the owner; do not ask the customer to pay again.

The customer redeems the code using the Google account they will use on future devices, then returns to Unlimited and selects Restore purchases. Tacklebox validates the signed Play receipt and acknowledges it through the existing billing flow. Neither contacting support nor entering a code locally grants access. Once redeemed, the normal Play entitlement can be restored on a new installation using that account. Existing grandfathered users can migrate before changing phones.

Release acceptance still requires the genuine Play licensing public key and a Play-installed build. Verify code redemption outside the app, returning/resuming, explicit restoration, reinstall using the same account, wrong-account failure, cancellation, revoked/refunded receipts, and offline use after a verified restore. No codes or real purchases were issued by this code change.

References checked 30 September 2026: [Android promo-code integration](https://developer.android.com/google/play/billing/promo) and [Play Console promotion setup](https://support.google.com/googleplay/android-developer/answer/6321495).
